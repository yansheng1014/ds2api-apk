## 系统要求

- Android 7.0+（minSdk 24）
- 仅支持 **arm64-v8a** 架构（主流 64 位手机均适用）

## 功能简介

- 在 Android 设备上本地运行 DS2API 服务端，提供 OpenAI / Claude / Gemini 兼容 API
- 内置 WebUI 管理界面（账号管理、API 测试、聊天记录、设置等）
- 内置 mihomo 内核（代理桥，安装后自动释放，无需手动下载）
- 服务通过前台服务保活，配合系统省电白名单使用效果更佳

## 使用提示

1. 安装后启动 App，服务监听 `http://127.0.0.1:5001`（管理界面 `/admin/`，API `/v1`）
2. 管理密钥显示在 App 主界面，首次使用请先添加账号
3. 如需代理桥功能，请在 WebUI 中配置订阅，mihomo 内核已随 APK 内置，无需手动下载
4. 首次启动会引导授予「忽略电池优化」，建议同意，否则息屏后服务可能被系统冻结

## 与系统代理共存（已修复，v4.0.0final 起）

早期版本与 FlClash / Clash / Surfboard 等**以 VPN 模式运行**的系统代理并存时，
会出现无法刷新 token、无法对话、节点出口测试报错等问题。原因：这类工具通过
`VpnService` 建立 TUN 虚拟网卡，**流量捕获发生在系统层面**，优先于任何应用进程；
本应用 mihomo 子进程连机场的流量同样被捕获，形成两层代理套娃。

**v4.0.0final 起已彻底解决，两种路径无需再二选一：**

1. **有系统代理时**：检测活动网络是否为 VPN，是则注入该 VPN 下发的 DNS，使解析返回
   **fake-ip** 并由系统代理接管出网，不再直连真实 IP 被 TUN 二次封装。
2. **无系统代理时**：走公共 DNS 拿真实 IP 直连。
3. **运行中途切换代理**：监听网络/VPN 切换，DNS 目标变化时自动重启子进程重新注入，
   代理 开/关 切换后再无残留旧 DNS 导致的 token 与对话卡死。

因此现在**手机代理 开/关 × 账号 走代理桥/不走，四种组合均可正常使用**。

> 若仍想手动限定出网路径（非必需）：
>
> - 用账号绑定节点（一号一 IP）→ 可关闭系统代理，出网交给内置代理桥；
> - 用系统代理统一出网 → 账号的代理节点留空，不启用代理桥。
